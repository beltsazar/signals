# Changelog

## 1.0.1 - 2024-06-20

## 1.0.0 - 2024-06-20
- Initial project setup with core signal system
- `Signal` class for reactive state management
- `ComputedSignal` class for derived reactive values
- `Watcher` class for observing signal changes
- Signal mixins for Web Components integration
  - `SignalsMixin` - Base mixin for signal support
  - `SignalsProviderMixin` - Provides signals to child components
  - `SignalsConsumerMixin` - Consumes signals from provider components
- `SignalsContextMixin` - Context-based signal propagation
- `freezeDeep` utility for immutable operations
- Comprehensive test suite with Vitest
- ESLint and Prettier configuration
- Vite build configuration
- Storybook stories for examples
- Feature example with product selection
- Composition pattern examples with flow components
- Mixin pattern examples with context propagation
